# Smoking Health Risk Analysis | Power BI Dashboard

An interactive dark-themed data analytics dashboard designed to visualize smoking habits, patient demographics, organ health impacts, and blood pressure/cholesterol risk factors.

## 📊 Dashboard Preview
![Dashboard Preview](./Smoking_Dashboard.png)

## 🚀 Project Overview
This project provides actionable insights into patient health data:
- **Patient Demographics & KPIs:** Tracks total patients, active/former smokers, smoking rate percentage, and total organ damage counts.
- **Organ-wise Health Impact:** Comparative analysis of which organs (Heart, Lungs, Liver, etc.) are most affected due to smoking.
- **Health Risk Factors:** Analyzes the relationship between patient BP risks (High, Low, Normal) and average cholesterol levels.
- **Smoking Status & Habits:** Distribution of daily cigarette consumption across current, former, and never-smokers.

## 🛠️ Built With & Tools Used
- **Tool:** Microsoft Power BI
- **Data Processing / Source:** Python, Pandas, CSV Datasets
- **Design Theme:** Custom Dark Mode Theme (`#050505` background, `#101010` panels, and `#F20D3A` pure red accents)
- **Interactive Features:** Real-time cross-filtering using slicers for Gender, Age Group, and Smoking Status.
